# World art and Necromancer integration

**Goal:** Deliver the approved Rogue's Odyssey style of pixel characters in solid 3D scenery, with Borrowed Hex's decaying, nightmarish mood.
**Spec:** Owner's approved in-chat design (3 October), GAME_PLAN.md sections 4 and 12. Work begins by explicit owner instruction; main branch only; preserve Claude's unfinished work.
**Architecture:** A presentation-only WorldPresentation component observes GameRoot.Sim, attaches to the existing character view, and builds meshes from the exact ArenaLayout. Scene dressing changes per encounter; analytic collision, telegraphs, input, simulation and player/ordinary-enemy art stay owned by existing systems. A repeatable editor importer prepares locally downloaded art using Unity APIs.
**Tech:** Unity 6000.3.25f1, URP, live Unity CLI.

Historical first-pass plan. The approved redesign supersedes its fixed-layout
scope; see `2026-10-03-world-redesign.md`. Latest authorization is commit only,
without push. First-pass Web output remains; further builds wait until preview.

## Boundaries
- Protected SHA256 inventory and backups: %TEMP%/BorrowedHex-art-20261003/protected.json and backup/. Never change or stage these files.
- Do not rerun ProjectBootstrap: it overwrites render/player settings and scenes.
- Public repository: downloaded art with redistribution restrictions stays in an ignored Resources/WorldArt folder; source importer and provenance document are committed. Runtime supports missing local art.
- No music/UI/player/standard-enemy changes. No gameplay rules or obstacle layout changes.
- Scenery height is cosmetic; the combat floor remains y=0. Ground effects do not replace exact gameplay telegraphs.
