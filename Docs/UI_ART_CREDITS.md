git-ignored `Assets/Game/Resources/UiArt` (or `WorldArt` for the fonts shared with the world),
and are rebuilt from the owner's downloads by `UiArtImporter`. Licence wording comes from the
evidence recorded in `Docs/WORLD_ART_HANDOFF.md` and the UI redesign plan (Q1, Task 1).
